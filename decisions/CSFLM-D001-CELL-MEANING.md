## Context

A 3x3 meaning matrix represents each state of a discourse. Rows are the metafunctions (ideational, interpersonal, textual). Columns are the register variables (field, tenor, mode). Systemic functional linguistics settles the diagonal: field with ideational, tenor with interpersonal, mode with textual, described by Hasan as a typical correlation (resonance), not an exclusive pairing. Halliday holds that all meaning is simultaneously ideational, interpersonal and textual.

## Open question

The six off-diagonal cells have no agreed reading. What does each cell mean, and where does the literature say each register variable bears on each metafunction?
