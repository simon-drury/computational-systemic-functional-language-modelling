# CSFLM-T2-SFL-TERMS

Tier 2. Systemic functional terms.

## The matrix

Rows: ideational, interpersonal, textual metafunctions. Columns: field, tenor, mode register variables. Entries are bounded in [-1, 1] by the current schema.

## Diagonal cells

Ideational-field, interpersonal-tenor, textual-mode. Hasan describes the resonance of metafunctions with the contextual parameters as a typical correlation, not an exclusive pairing.

## Off-diagonal cells

Open question. See decisions/CSFLM-D001-CELL-MEANING.md. No source yet defines these six cells.
