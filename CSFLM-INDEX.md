# CSFLM-INDEX

This repository defines the 3x3 meaning matrix: what each of its nine cells means, how a cell value is formed from systemic functional features, and how models read and write it. Models and trained weights live in other repositories and read this definition.

| Code | Reader | Content |
|---|---|---|
| CSFLM-T1-VIGNETTE | anyone, read aloud | one clause followed through to its matrix |
| CSFLM-T2-SFL-TERMS | linguists | the nine cells in SFL terms, with sources |
| CSFLM-T3-FORMAL | engineers, reviewers | schema, feature-to-cell function, diagrams |
| decisions/CSFLM-D001-CELL-MEANING | decision makers | open question on the six off-diagonal cells, same brief for every model |
| consumers/CSFLM-C001-ENCODERS | engineers | three ways a model can read the matrix: flat, axis mixing, diagonal core |
